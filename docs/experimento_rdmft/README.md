# Planejamento do experimento com osciladores harmônicos interagentes

Proposta para revisão antes da implementação. A primeira entrega deve reconstruir estados de dois osciladores com marginais térmicas idênticas, comparar o estado produto, o ótimo condicionado exato na mesma base e a solução entrópica, e medir separadamente factibilidade, regularização e truncagem.
